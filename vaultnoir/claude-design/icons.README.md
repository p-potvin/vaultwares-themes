# Icons

Panopticam's hand-drawn set, extended for the catalog: 61 icons on a 20px grid, 1.6 stroke, round caps and joins, outline only (filled only in the `-filled` variants). In code they use `currentColor` and take the text colour; these copies are drawn in a single ink, `#8d93a0` (`vwnr-muted`, dark theme), so they read on both themes here. Use them at 16, 18 or 20px. `ask.svg` (the circles) is the emblem and the Ask bar's icon. Source: `vaultwares-themes/vaultnoir/icons/icons.json`; React components in `bundle.js` (`vaultnoir.IconAsk`, …).
