# vaultnoir: Design System

Panopticam's UI turned into a reusable design system (operator, Sun, 22 Nov 2026). Its first user is the
vault-raggae catalog desktop app (Tauri 2). Panopticam, the shared-tube admin and other media-heavy tools can adopt it
later.

| | vaultsqware | vaultnoir |
|---|---|---|
| Built from | the VaultWares Redesign | Panopticam's UI |
| Regions | console (obsidian) + warm (bone) rail, together | one surface: near-black (dark) or near-white (light) |
| Modes | none (both regions at once) | dark (default) and light, `data-theme` |
| Accent | iris + coral | one accent, five choices: red (default), sky, violet, pink, amber, `data-accent` |
| Fonts | Manrope + SUSE Mono | Inter Tight + JetBrains Mono |
| Icons | 164 gapped-edge | Panopticam's hand-drawn set, extended (61) |
| Navigation | warm rail | 56 px top bar, most-used pages first, "All pages" menu |

## The design contract (agreed Sun, 22 Nov 2026)

- **Colour**: Panopticam's neutrals (`#0a0b0e` to `#1e222a`) plus a light counterpart built from the same tokens.
  - Accents: red `#ff3b4e` is the default; the others are `#27b6f2`, `#9070cc`, `#e0529b` and `#f0a63a`.
  - Each accent is tuned per mode to pass WCAG AA. The values are in [TOKENS.md](./TOKENS.md).
- **Navigation**: Panopticam's top bar holds the brand, pinned pages, "All pages", G+letter shortcuts, the Ctrl+K
  finder and a status pulse.
  - Pinned pages are ordered by how often this viewer uses them; the home page (Browse) always comes first.
  - Pages that don't fit move into "All pages"; nothing collapses to icons.
- **Search**: each page has a toolbar row under the top bar.
  - It holds the word search on the left and the **Ask bar** on the right: circles icon, a how-to tooltip, and "Read
    as" chips below it.
  - The Ask bar never replaces the main search.
- **Density**: Panopticam's.
  - Cards are 180 to 220 px (a slider sets the size) in an auto-fill grid with 12 px gaps.
  - Body text is 13 to 14 px and rows are 36 px.
- **Controls**:
  - Buttons are 34 px high (28 px small), padded 0 12 px, with an 8 px radius. The primary button is an accent fill
    with its label colour; secondary is surface + line; ghost is text only.
  - Inputs are 38 px with a 9 px radius.
  - Chips are 30 px with an 8 px radius; "on" is surface-3 plus an inset line.
  - Badges are pills.
- **Icons**: 20 px grid, 1.6 stroke, round caps, outline only, `currentColor`, used at 16, 18 and 20 px. They are
  filled only for "on" variants.
- **Type**: Inter Tight and JetBrains Mono, packaged locally.
  - Body is 14 / 1.45 on a 1.2 scale (12, 14, 17, 20, 24, 29).
  - Mono is used for numbers, durations, ids and keys.
- **Motion**: 120 to 150 ms ease-out on hover, focus, chips, menus and toasts. There are no page transitions and no
  hover scrub; all motion is off under reduced motion.
- **Signals**:
  - Success, danger, warning and info always come with a word or an icon.
  - Charts use the five accents as categories, plus a ramp of the active accent.
- **States**:
  - Loading shows skeletons at final size; a spinner only for actions under 1 s.
  - Empty states give one line saying why, plus one action.
  - Errors appear inline with the gateway's message and a Retry button; toasts are for background events only.
  - Selection is a 2 px accent ring on cards and surface-3 on rows. The focus ring is 2 px `--vwnr-focus`.
- **Sizes**: desktop-first, with breakpoints at 800, 1200 and 1600 px and a minimum of 800 x 560. Click targets are
  at least 32 px.
- **Accessibility**: WCAG AA in both modes for every accent, and everything works from the keyboard:
  - G+letter goes to a page, Ctrl+K opens the finder, `/` focuses the search and `A` the Ask bar.
  - The arrows move between cards and Enter opens one.
  - 4 3 2 1 rate, and `?` shows the key sheet.
- **Voice**: terse and plain, in sentence case. Tooltips say how to use a thing in one or two lines. English and
  Quebec French.
- **Out of scope for v1**: a Qt / Python port, and right-to-left layouts. Phone widths and print are not ruled out
  (print is a minimal stylesheet).

## Files

- [vaultnoir.css](./vaultnoir.css): fonts, tokens, geometry, type, motion and base elements.
- [tokens.css](./tokens.css) and [tokens.json](./tokens.json): every colour. Generated by
  [tools/build_tokens.py](./tools/build_tokens.py), which also checks the contrast.
- [components.css](./components.css): the `vwnr-*` components. See [COMPONENTS.md](./COMPONENTS.md).
- [react/](./react/index.tsx): typed React 19 wrappers, which also re-export every icon. They work in Preact through
  `preact/compat`.
- [icons/](./icons/icons.json): the source, plus `svg/`, `sprite.svg` and `react/index.tsx`, all built by
  `icons/build.py`.
- [fonts/](./fonts/fonts.css): Inter Tight and JetBrains Mono, both variable and under the SIL OFL. Latin and
  latin-ext only.
- [preview/](./preview/src/main.tsx): a live page with every component in both modes and all five accents.

## Usage

```html
<html class="vwnr" data-theme="dark" data-accent="red">
<link rel="stylesheet" href="vaultnoir/vaultnoir.css" />
<link rel="stylesheet" href="vaultnoir/components.css" />
```

```tsx
import { TopBar, Toolbar, Search, AskBar, ReadAs, Grid, Card, useTheme } from "vaultnoir/react";
```

Preview: `npm install` then `npm run dev` in `preview/` (port 5288).

Never use a raw hex outside `tokens.css`: reference the `--vwnr-*` tokens.
