# VaultWares Themes Instructions

Always use the new VaultWares Redesign for everything related to styling/branding/assets
In addition, this repo contains VaultWares' philosophy, goals, modus operandi. See theme_manager to easily import the theme into your app.

## Approved sibling design systems

- **vaultnoir** (`vaultnoir/`, operator decision Sun, 22 Nov 2026): Panopticam's UI as a design system, for
  media-heavy tools (first: the vault-raggae catalog desktop app; later Panopticam, the shared-tube admin). Use it
  where an app has chosen it; everything else keeps the Redesign. Its contract is `vaultnoir/README.md`; Claude
  Design copy: https://claude.ai/artifact/UeYNyrWs3qE7AB8P74RYPZ.
- **vaultsqware** (`vaultsqware/`): the Redesign's tooling palette (Anything and other internal tools).
